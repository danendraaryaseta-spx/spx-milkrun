How to set up — connect your Google Sheets

You need 3 published Google Sheet tabs — one for each data type. Do this once; after that just update the sheets and click Reload.

  1. Open your Google Sheet. Make sure it has 3 tabs with the correct columns:
    ADO tab —
    dclmadocitytype
    Travel time tab —
    origin_stationdest_stationroute_typeduration_final
    LM cutoff tab —
    lm_station_namelast_1triplast_multi
  2. For each tab: go to File → Share → Publish to web, select that tab, choose CSV, click Publish, copy the URL.
  3. Paste each URL into the fields below and click Load all data.
  4. URLs are saved in your browser — next visit just click Reload.
